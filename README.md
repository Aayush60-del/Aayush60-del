> Full-stack e-commerce platform for hill artisans

- ⚙️ **Stack:** HTML, CSS, JavaScript, Node.js, Express, MongoDB
- 🔐 JWT-based authentication + product APIs + cart management
- 📱 Responsive design with search, wishlist & category browsing
- 🔗 [Live Demo](https://github.com/Aayush60-del/Pahadi-kart)

---

### 🎵 [Symponify](https://github.com/Aayush60-del/Symponify-) — Music Streaming App
> Spotify-inspired music streaming web application

- ⚙️ **Stack:** React, Node.js, Express, MongoDB
- 🎧 JWT auth, playlists, liked songs, album browsing
- 🛠️ Admin panel for uploading & managing songs/albums
- ☁️ Deployed on **Vercel** (frontend) & **Render** (backend)
